Project Overview

This was a solo project submitted for my COMP270: Mathematics for 3D Worlds & Simulations module in second year. The goal of this module was to learn the fundamental mathematics involved in the design and development of real-time 3D worlds and simulations. For this module we were given 4 worksheets to complete with the first 3 being more specific in requirements whilst the 4th was more open with VFX/mesh manipulation involved.For the 4th worksheet the effect I created was a tornado which is created from a cylinder mesh that was manipulated. Whilst also creating a shader graph to add additional effects to the look of the tornado.

Mesh Generation

For the tornado itself it is made with two meshes. One of these meshes contains the larger mesh which is used for the wind material and the smaller is used for the colouring of the tornado. These meshes are built using a mesh builder script which adds all the triangles, vertices, normal's and UVs to the mesh after they have been calculated. These are calculated through the Proceduralbase script which has a function that will build rings which are used to create each section of the tornado and connect them together to make it one solid mesh. This also allows the user to change the height, radius and number of segments within the mesh that is generated.
